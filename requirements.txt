#   pip install -r requirements.txt
#
# ============================ 为什么要写版本下限 ============================
# 这里是 `>=` 而不是 `==`。
#
# 取舍是：
#   `>=`  → 灵活，能拿到安全补丁和新特性；代价是"我这能跑，你那不一定"
#   `==`  → 可复现，所有人装出来的完全一样；代价是升级要手动一个个改
#
# 我们在开发期用 `>=`（迭代快），
# **发布 1.0 之后会补一份 requirements.lock.txt 用 `==`** ——
# 两件事不冲突：requirements.txt 说"我要什么"，lock 说"我验过哪个组合"。
#
# （这个权衡和「上下文压缩压到多少」是同一类问题：
#   灵活性和确定性之间的取舍，答案取决于你处在什么阶段。）
